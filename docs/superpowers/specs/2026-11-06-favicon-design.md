# Favicon: the CV monogram

## Intent

The site has no icon, so browser tabs, bookmarks and phone home screens show a blank page. Tony chose the monogram from five drafts: "CV" in Instrument Serif, the logo's face, in ink (#0a1c57) on a sky-blue (#dfebff) rounded square. It ties the tab to the wordmark.

## Goals

- One icon across the landing page, the signed-in app, bookmarks and phone home screens.
- Readable at 16px in both light and dark browser tab bars.

## Non-goals

- No change to the on-page "CV Tailor" wordmark.
- No web app manifest or install prompt.

## Anti-goals

- Letters shown in a fallback font, because the icon relied on the web font.
- A new package in the repo just to make the icon.

## Approaches

1. **Fixed image files in `apps/web/app/` (chosen).** Convert the letters to outlines once, from Instrument Serif's font file, and add the files Next.js picks up by name. Looks right everywhere, costs nothing at runtime, and allows hand-tuning for 16px. Redoing it means regenerating the files.
2. **An icon generated by code at build time.** Easy to change later, but it pulls the font file into the build and makes 16px tuning harder.
3. **SVG only.** Smallest change, but older browsers, some bookmark and share views, and iPhone home screens get no icon.

Tony picked 1.

## What gets built

- `apps/web/app/icon.svg`: the monogram, with the letters as outlined paths and no font reference.
- `apps/web/app/favicon.ico`: 16px and 32px versions, for older browsers and bookmarks.
- `apps/web/app/apple-icon.png`: 180px for iPhone home screens. A full square, because iOS rounds the corners itself.
- The outlines come from Instrument Serif's own font file. The script that converts them runs in a scratch folder outside the repo, so the repo gains no dependency.

## Left to the builder (Claude's calls)

- The letters carry a stroke in the same ink, heaviest where the icon is smallest: 1.1 units (of 32) in the 16px ICO entry, 0.7 in `icon.svg` (browsers mostly show it at 16px), 0.6 at 32px and 0.25 on the 180px home-screen icon. At the first try, unstroked letters looked grey and hairline even at 32px.
- The letters are set a little larger than in the draft (24 units instead of 21, about 56% of the square's height), centred, for the same reason.
- `proxy.ts` lets signed-out visitors fetch `apple-icon.png`, as it already did for `favicon.ico` and `icon.svg`. Otherwise a home-screen icon saved from the landing page would be a login redirect.
- Check by rendering each file at its real size in light and dark tab mock-ups, and by running `next build`, which reports a malformed icon file.
